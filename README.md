# 泓聊社区平台

线上地址：https://yhdet.ccocc.cyou/

泓聊是一个基于 React + FastAPI 开发的社区交流平台，支持帖子发布、评论互动、用户登录、内容举报、市场订单和后台管理等功能。

## 技术栈

- 前端：React、JavaScript、CSS3、Axios
- 后端：FastAPI、SQLite、WebSocket
- 部署：Docker、Nginx / OpenResty

## 主要功能

- 帖子列表、帖子详情、评论区和用户交互
- 用户登录、权限控制和跨端状态同步
- 市场订单、商品展示和后台处理
- 内容举报闭环：举报、审核、驳回、删除内容和处理状态更新
- 后台治理总览：待处理举报、市场待办、冻结用户、封禁用户等数据集中展示
- WebSocket 实时交互和线上部署运维
